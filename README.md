# Ra-Thoriq_Rahmah
Sistem Ra-Thoriq-Rahmah merupakan sebuah aplikasi yang dirancang untuk membantu pengelolaan data penilaian perkembangan bakat anak secara terstruktur, efektif, dan efisien. Sistem ini dikembangkan sebagai solusi digital untuk menggantikan proses pencatatan manual yang cenderung rentan terhadap kesalahan.
